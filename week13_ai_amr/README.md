# Week 13 - AI 기반 AMR 통합

## 목표
YOLO 계열 객체 인식 결과를 ROS 2/AMR 시스템과 연계하여 AI 인지 기반 행동을 구현한다.

## 프로젝트 예시
- 사람 검출 시 감속/정지
- 지정 객체 검출 시 상태 메시지 발행
- 표지판/색상/객체에 따라 목표 행동 변경
- 카메라 AI 결과를 navigation safety layer와 연동

## 안전 원칙
AI 검출 결과만으로 실제 고속 구동을 직접 제어하지 않는다. 실습은 저속, 제한구역, 비상정지 장치가 있는 환경에서 수행한다.

## 제출물
노드 구성도, 상태 전이 로직, 실제 동작 결과, latency 측정
