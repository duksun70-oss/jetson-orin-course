# 참고 오픈소스

수업 준비 시 다음 공개 프로젝트를 우선 참고한다.

- NVIDIA-AI-IOT/jetson_benchmarks: Orin 성능 측정
- dusty-nv/jetson-inference: TensorRT 기반 비전 실습
- dusty-nv/jetson-containers: Jetson 컨테이너 환경
- NVIDIA-AI-IOT/jetcam: 카메라 입문
- NVIDIA-AI-IOT/deepstream_python_apps: 산업형 영상 파이프라인
- NVIDIA-ISAAC-ROS/isaac_ros_common: ROS 2/Isaac ROS 기반 로보틱스
- rbonghi/jetson_stats: jtop 시스템 모니터링
- jetsonhacks/jetson-orin-librealsense: RealSense 설정 참고

## 라이선스 주의
공개 저장소라도 코드 복제/수정/재배포 조건은 각 저장소 LICENSE를 확인해야 한다. 수업 자료에는 원 출처와 라이선스를 명시하고, 필요 시 직접 재작성한 예제를 사용한다.
