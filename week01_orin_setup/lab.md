# Week 01 Lab — 환경 Baseline 만들기

## 목표
장비 상태를 재현 가능하게 기록한다.

## 절차
1. `bash setup/system_check.sh` 실행.
2. OS/L4T/CUDA/Python/OpenCV 결과 저장.
3. `jtop` 또는 가능한 시스템 모니터링 도구로 CPU/GPU/RAM/온도 확인.
4. 장비 모델·RAM·저장장치·전원모드 기록.
5. `instructor/environment_baseline.md` 형식으로 개인 Baseline 작성.

## 결과표
모델 / JetPack / L4T / CUDA / OpenCV / Idle 온도 / 저장공간.

## 제출
환경 점검 로그 + 1페이지 분석.
