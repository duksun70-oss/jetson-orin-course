# Week 01 - Jetson Orin 및 JetPack 환경 구축

## 학습목표
- Jetson Orin 계열 구조와 JetPack 소프트웨어 스택을 이해한다.
- OS, L4T, CUDA, Python, OpenCV 상태를 점검한다.
- jtop을 이용해 CPU/GPU/메모리/온도/전력을 관찰한다.

## 실습
1. `bash setup/system_check.sh`
2. Python/OpenCV/CUDA 버전 기록
3. `jtop` 실행 후 CPU/GPU/메모리/온도 캡처
4. 전력 모드가 허용되는 장비에서는 현재 모드 확인

## 제출물
- 시스템 점검표
- jtop 화면
- 사용한 Jetson 모델, RAM, 저장장치, JetPack/L4T 버전

## 심화
동일 모델에서 전력 모드에 따른 간단한 AI 추론 성능 차이를 예상해본다.
