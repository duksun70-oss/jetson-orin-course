# Week 12 - SLAM + Nav2

## 학습목표
- Odometry, TF, map, localization의 관계를 이해한다.
- SLAM으로 2D 지도를 생성한다.
- Nav2를 이용하여 목표점 주행을 수행한다.

## 실습
1. 센서/odometry topic 확인
2. SLAM 실행 및 실내 지도 작성
3. map 저장
4. localization
5. RViz에서 goal 전송
6. 장애물 발생 시 local planner 동작 관찰

## 제출물
생성 map, TF tree, 주행 경로 캡처, 실패 사례와 원인 분석
