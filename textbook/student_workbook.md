# 학생용 실습지

## 공통 작성 항목
- 실습 주차 / 팀명 / 이름
- 사용 장비: Jetson 모델, 카메라, 센서, 저장장치
- 소프트웨어 버전: JetPack, L4T, CUDA, Python, OpenCV, PyTorch, ROS 2
- 목표: 이번 실습에서 확인할 기술적 질문 2개
- 실행 명령: 실제 입력한 명령어 전체
- 결과: 화면 캡처, 로그, 표, 그래프
- 분석: 예상과 다른 점, 원인, 개선안

## 주차별 핵심 질문
1주: JetPack과 L4T 버전을 왜 기록해야 하는가?
2주: Jetson GPIO에 5V를 직접 입력하면 왜 위험한가?
3주: 해상도를 높이면 FPS가 낮아지는 이유는 무엇인가?
4주: 작은 행렬 연산에서 GPU가 항상 빠르지 않은 이유는 무엇인가?
5주: CPU/GPU 추론 latency 측정 시 warm-up이 필요한 이유는 무엇인가?
6주: TensorRT FP16 최적화의 장점과 위험은 무엇인가?
7주: confidence와 NMS가 객체검출 결과에 주는 영향은 무엇인가?
8주: 중간 프로젝트에서 가장 큰 병목은 어디였는가?
9주: ROS 2 topic 구조가 단일 스크립트보다 유리한 이유는 무엇인가?
10주: timestamp와 frame_id가 센서 융합에서 중요한 이유는 무엇인가?
11주: point cloud 데이터의 노이즈를 어떻게 평가할 수 있는가?
12주: SLAM 지도 품질을 나쁘게 만드는 요인은 무엇인가?
13주: AI 검출 실패 시 AMR은 어떤 fail-safe 동작을 해야 하는가?
14주: 최종 프로젝트의 기술적 차별성과 한계는 무엇인가?

## 보고서 평가 체크리스트
- 재현 가능한 명령어와 버전 정보가 있는가?
- 결과가 정량값으로 제시되었는가?
- 오류 메시지와 해결 과정이 기록되었는가?
- 안전 조건을 준수했는가?
- 단순 결과 나열이 아니라 원인 분석과 개선안이 있는가?
