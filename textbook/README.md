# Jetson Orin 정식 대학 실습교재

이 폴더는 기존 14주 실습 플랫폼을 대학 정규교과 교재 수준으로 확장한 자료입니다.

## 구성
- `detailed_theory_textbook.md`: 14주 상세 이론교재
- `detailed_lab_manual.md`: 회로도·시스템 구성도·실습 절차·Troubleshooting 포함 실습매뉴얼
- `student_workbook.md`: 학생용 실습지와 보고서 작성 문항
- `instructor_solution_guide.md`: 교수자용 정답, 해설, 채점 포인트
- `slide_deck_outline.md`: PPT 제작용 주차별 슬라이드 구성안

## 운영 원칙
각 주차는 이론 이해, 환경 점검, 안전 확인, 단계별 실습, 정량 측정, 오류 분석, 개선 제안 순서로 운영한다. Arduino 저장소는 저수준 센서·액추에이터 제어, Jetson Orin 저장소는 Edge AI·ROS 2·SLAM·AMR 통합을 담당한다.
