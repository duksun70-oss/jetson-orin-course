# 중간 통합 프로젝트

## 목표
Camera + Object Detection + Jetson 성능 모니터링을 단일 실시간 파이프라인으로 통합한다.

## 필수 요구사항
- 실시간 Camera 입력
- 객체검출 결과 bbox/class/confidence 표시
- FPS 또는 frame latency 표시
- GPU/Memory 또는 시스템 상태 최소 1종 기록
- 3개 이상의 실패 사례 분석

## 제출물
코드, 실행영상, 시스템 구성도, 5쪽 이내 기술보고서.

## 루브릭
기능 35 / 성능측정 20 / 오류분석 15 / 코드구조 10 / 보고서 10 / 발표 10.
