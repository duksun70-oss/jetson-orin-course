# 장비 체크리스트

## 공통
- [ ] Jetson Orin 본체 및 안정적 전원
- [ ] 냉각팬/히트싱크 정상
- [ ] HDMI/모니터 또는 SSH 접속
- [ ] 키보드/마우스
- [ ] 저장공간 20GB 이상 여유
- [ ] 인터넷 또는 사전 다운로드 패키지

## 비전
- [ ] USB/CSI Camera
- [ ] 조명 환경

## 로봇
- [ ] 모터 드라이버 및 독립 모터전원
- [ ] 비상 정지 또는 즉시 전원 차단 수단
- [ ] 2D LiDAR 또는 Depth Camera
- [ ] Arduino/MCU(선택)

## 수업 시작 전 기능시험
Camera → GPU → ROS 2 → Sensor → Motor 순으로 개별 확인 후 통합한다.
