# 교수자 운영 가이드

## 수업 전
1. 모든 Jetson의 모델, RAM, JetPack/L4T, CUDA, Python, OpenCV를 동일 기준으로 기록한다.
2. 각 장비의 카메라·센서·전원·저장공간을 점검한다.
3. 실습 예제는 수업 전 실제 장비에서 실행 검증한다.
4. 버전 차이가 있는 경우 명령을 강의자료보다 장비 Baseline에 맞춘다.

## 수업 중
- 결과보다 재현성과 측정 절차를 강조한다.
- 성능 수치는 단일 실행이 아니라 warm-up 후 반복 측정한다.
- 오류 발생 시 로그→가설→검증→수정 순서를 보고서에 남기게 한다.

## 채점 원칙
기능 구현 40%, 측정/분석 25%, 문제해결 과정 20%, 문서화/재현성 15%를 기본으로 하되 프로젝트 루브릭을 우선한다.
