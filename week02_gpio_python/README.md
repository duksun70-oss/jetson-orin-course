# Week 02 - Linux, Python, GPIO

## 학습목표
- Linux 파일/권한/프로세스 기본 명령을 익힌다.
- Python으로 디지털 I/O와 PWM 개념을 이해한다.
- Jetson GPIO 사용 시 보드별 핀맵과 전압 레벨을 확인한다.

## 실습
- 터미널 명령: `pwd`, `ls`, `cd`, `ps`, `top`, `chmod`
- Python 기본 문법 및 모듈
- LED 출력 또는 PWM 밝기 제어

## 안전
Jetson GPIO는 3.3V 로직이다. 5V 신호를 직접 입력하지 않는다.

## 제출물
GPIO 핀 구성도, 실행 코드, PWM duty 변화 결과
