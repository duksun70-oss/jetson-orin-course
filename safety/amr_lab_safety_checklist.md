# AMR/Jetson Orin 실습 안전 체크리스트

## 전원 및 하드웨어
- Jetson 전원 어댑터 정격 확인
- 배터리 사용 시 극성, 전압, 과전류 보호 확인
- 모터 드라이버와 Jetson GND 공통 연결 확인
- GPIO에 5V 신호 직접 입력 금지
- 팬과 방열판 동작 확인

## 주행 실습
- 실습 공간에 사람과 장애물을 최소화
- 저속 모드에서 먼저 시험
- 비상정지 버튼 또는 수동 전원차단 방법 확보
- AI 인식 실패 시 정지하도록 설계
- 첫 시험은 바퀴를 들어 올린 상태 또는 시뮬레이터에서 검증

## 데이터·소프트웨어
- 외부 오픈소스 코드는 LICENSE 확인
- 카메라 영상에 개인정보가 포함되지 않도록 주의
- 모델 결과를 제어 명령에 직접 연결하지 않고 상태판단 노드를 둔다
