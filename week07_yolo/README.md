# Week 07 - YOLO 실시간 객체 인식

## 학습목표
- Object Detection의 bounding box, confidence, NMS를 이해한다.
- Jetson에서 카메라 기반 실시간 객체 검출을 수행한다.
- FPS와 정확도에 영향을 주는 입력 해상도/모델 크기를 분석한다.

## 실습
- 강사가 지정한 YOLO 계열 모델 설치
- 이미지 1장 추론
- USB/CSI camera 실시간 추론
- 모델 크기 또는 입력 크기별 FPS 비교

## 제출물
검출 화면, FPS, 주요 class별 confidence, 오검출/미검출 사례 3건 분석
