# 교과목 명세서

## 교과목명
Jetson Orin 기반 Edge AI 및 자율이동로봇 실습

## 권장 대상
기계·전기전자·AI·로봇·모빌리티 계열 3~4학년. Python 기초와 Linux 명령어 경험을 권장한다.

## 수업 목표
Edge AI 하드웨어와 로봇 소프트웨어를 연결해 실제 시스템을 설계·구현·검증하는 역량을 기른다.

## 교과목 학습성과(CLO)
- CLO1: Jetson Orin 하드웨어/JetPack 소프트웨어 스택을 설명한다.
- CLO2: GPU 가속 및 TensorRT 최적화 성능을 정량 비교한다.
- CLO3: 카메라/센서 데이터를 Python 및 ROS 2로 처리한다.
- CLO4: SLAM/Nav2 기반 자율이동 파이프라인을 구성한다.
- CLO5: AI 인지+AMR 통합 시스템을 팀 단위로 설계·시연·분석한다.

## 평가
- 주차별 실습 및 보고서 30%
- 중간 통합 프로젝트 20%
- 최종 프로젝트 40%
- 출석·토론·안전수칙 준수 10%

## 성취수준
A: 독립 구현+정량 검증+문제 해결 근거 제시 / B: 요구 기능 충족+기본 분석 / C: 부분 구현 / D 이하: 재현 불가 또는 핵심 기능 미완성
