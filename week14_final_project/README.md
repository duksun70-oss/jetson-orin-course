# Week 14 - 최종 프로젝트

## 주제
Jetson Orin 기반 AI 자율이동/AMR 시스템을 팀별로 구현하고 시연한다.

## 최소 요구사항
- Jetson Orin 사용
- ROS 2 기반 최소 3개 node
- Camera 또는 LiDAR/Depth sensor 1종 이상
- AI inference 기능 1개 이상
- 성능 측정(FPS 또는 latency, CPU/GPU/메모리)
- 재현 가능한 설치/실행 README

## 권장 아키텍처
Sensor → Perception → Decision/Safety → Navigation/Control → Monitoring

## 평가 예시
- 시스템 통합 30
- AI/인지 기능 20
- ROS 2/소프트웨어 구조 15
- 성능 및 실험 분석 15
- 안전/재현성 10
- 발표/시연 10

## 최종 제출
소스코드, README, 시스템 구성도, 실험표, 시연 영상, 최종 발표자료
